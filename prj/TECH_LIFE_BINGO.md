# Tech Life Bingo

A fun bingo game for developers. Mark a square when a statement matches your coding habits, IDE preferences, or developer culture experience.

## How to play

- Print or open this file in your editor.
- Mark squares that apply to you.
- Get 5 in a row horizontally, vertically, or diagonally to win.
- Share the card with teammates and compare results.

| B | I | N | G | O |
|---|---|---|---|---|
| I have an IDE theme named after a snack | I use keyboard shortcuts more than the mouse | I have an open-source contribution on GitHub | I’ve used Vim mode in an editor | I own more than one mechanical keyboard |
| I debug by printing logs first | I customize my IDE settings for each project | Free Space | I have a favorite pair of headphones for coding | I’ve attended a hackathon in the last year |
| I’ve renamed a branch because the name was too weird | I know my editor’s font size shortcut | I write unit tests before solving a bug | I’ve used a standing desk while coding | I have a `TODO` comment older than 6 months |
| I’ve tried at least three different IDEs | I code in the dark mode after 8pm | I’ve used a plugin to auto-format code | I’ve read a whole programming book in a weekend | I’ve written a script to automate a boring task |
| I keep multiple terminal tabs open | I pair-programmed remotely | I’ve customized my editor status bar | I’ve joined a developer community online | I’ve accidentally committed a secret key |

## Notes

- This bingo is meant to be light-hearted and flexible.
- Feel free to replace any square with your own developer habit or culture moment.
